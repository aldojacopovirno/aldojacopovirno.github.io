# Images Directory

Questa cartella contiene le immagini per i post del blog.

**Nota importante:** Questa cartella è inclusa nel .gitignore e non viene pubblicata nel repository pubblico.

## Come usare le immagini:

### Opzione 1: Hosting esterno
Puoi caricare le immagini su un servizio di hosting esterno (es. Imgur, Cloudinary, GitHub Issues) e usare l'URL completo nel front matter:

```yaml
cover_image: https://example.com/path/to/image.jpg
```

### Opzione 2: Repository pubblico separato
Crea un repository pubblico separato solo per le immagini e referenzialo via URL.

### Opzione 3: Cartella pubblica
Se vuoi che alcune immagini siano nel repository, crea una cartella `assets/images/` (NON questa cartella) e usala per immagini pubbliche.
